# Ironclad Systems Website

A professional website for Ironclad Systems, a software development company.

## Features

- Modern, responsive design
- Clean and professional look
- Fully responsive layout that works on all devices
- Smooth scrolling navigation
- Interactive elements with JavaScript
- Contact form functionality

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (ES6+)
- Google Fonts (Roboto and Montserrat)

## Project Structure

```
.
├── index.html          # Main website page
├── styles.css          # Cascading style sheets
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## How to Run

1. Simply open `index.html` in any modern web browser
2. The site is fully self-contained with no external dependencies

## Sections

1. **Header** - With navigation and logo
2. **Hero Section** - Main banner with call-to-action
3. **About Us** - Company information
4. **Services** - List of services offered
5. **Portfolio** - Sample projects
6. **Contact** - Contact form and information
7. **Footer** - Copyright information

## Responsiveness

The website is fully responsive and will adapt to different screen sizes:
- Desktop
- Tablet
- Mobile

All images are placeholders in this implementation but can be replaced with actual project images.

## Customization

To customize the website:
1. Modify `index.html` to change content
2. Update `styles.css` to change colors, fonts, and layout
3. Edit `script.js` to modify interactive elements

This template provides a solid foundation for a software company website that can be easily extended with additional features.
