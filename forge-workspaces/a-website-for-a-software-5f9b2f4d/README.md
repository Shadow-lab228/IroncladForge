# Ironclad Systems Website

A modern, responsive website for Ironclad Systems, a software company focused on secure and scalable solutions.

## Features

- Responsive design that works on all device sizes
- Modern UI with smooth animations and transitions
- Clean and professional styling
- Interactive elements with JavaScript functionality
- Section-based navigation

## Structure

- `index.html` - Main page structure
- `styles.css` - All styling for the website
- `script.js` - Interactive functionality

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript ES6+
- Responsive design principles

## Getting Started

To view the website locally:

1. Open `index.html` in any modern web browser
2. No build process required

## Customization

The website can be easily customized by modifying:
- Content in `index.html`
- Styles in `styles.css`
- Interactivity in `script.js`
