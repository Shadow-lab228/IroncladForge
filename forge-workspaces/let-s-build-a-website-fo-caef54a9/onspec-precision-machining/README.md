# Onspec Precision Machining Website

This repository contains the complete website code for Onspec Precision Machining, a machinist shop that provides precision engineering solutions.

## Project Structure

```
onspec-precision-machining/
├── index.html          # Main HTML entry point
├── src/
│   └── index.js        # React application entry point
├── package.json        # Dependencies and scripts
└── README.md           # This file
```

## Features Implemented

1. **Responsive Design** - Works on mobile, tablet, and desktop devices
2. **Modern UI** - Clean, professional design appropriate for a precision machining business
3. **Complete Navigation** - Header with navigation links to different sections
4. **Key Pages**:
   - Home page with hero section and key services
   - About page with company story and team information
   - Services page showcasing machining capabilities
   - Contact page with form and information

## Technologies Used

- React.js for component-based architecture
- Tailwind CSS for styling
- Responsive design principles
- Modern JavaScript (ES6+)

## How to Run

1. Navigate to the project directory: `cd onspec-precision-machining`
2. Install dependencies: `npm install`
3. Start development server: `npm start`

The website will be available at http://localhost:5000

## Website Content

The site focuses on showcasing:
- Precision machining services
- Quality assurance practices
- Industry expertise (aerospace, automotive, medical)
- Contact information and inquiry process
